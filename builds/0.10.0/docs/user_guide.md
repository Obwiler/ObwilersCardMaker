# DZ CardMaker 用户指南

## 快速开始

### 环境要求
- Rust 1.75+
- Node.js 18+
- Tauri CLI v2

### 安装与启动
```bash
cd builds/0.10.0
npm install
cargo tauri dev
```

### 卡片目录结构
```
cards/
├── _distribution.json   # 配比表（160张实例配比）
├── ZY01-儒家/           # 阵营卡 01
│   └── card.dz          # DZ 语法源文本
├── ZY06-斥候/           # 职业卡
├── GZ01-重锤/           # 构筑卡（兵刃）
└── JB01-击敌/           # 基本牌
```

## DZ 语法速查

### 卡牌声明行
```
卡名 [类型, 属性1, 属性2]
```

| 类型 | 属性说明 |
|------|---------|
| 阵营 | `生命N, 护甲N, 技力N` |
| 职业 | — |
| 兵刃/宝器/甲胄/武学/术法 | `被动` 或 `主动` |
| 基本牌 | `白` `蓝` `紫` `橙` |

### 效果标记符号
| 符号 | 含义 |
|:----:|------|
| `：` | 触发条件。行末，表示"当……时" |
| `—` | 常驻被动。行首，无条件持续生效 |
| `？` | 判定分支。行首，互斥分支 |
| `·` | 多选一。行首，平行互斥选项 |
| `「」` | 标记引用。行中，引用标记名 |
| `[ ]` | 备注约束。行尾：次数/上限/互斥/说明 |

### 阵营卡范例
```
儒家 [阵营, 生命8, 护甲2, 技力4]

  核心技能：仁怀

    获得白或紫基本牌时，积累1个「仁心」标记[每回合最多3个]。
    消耗1个「仁心」，恢复1点技力。
```

### 职业卡范例
```
药师 [职业]

  回合开始时，获得1个「材料」标记[上限4个]。

  点石成金：
    ·消耗1个「材料」并弃1张手牌，获得1点护甲[每配方每回合1次]。
    ·消耗1个「材料」并消耗1点生命，获得2点技力[每配方每回合1次]。
```

### 构筑卡范例
```
浮光 [武学, 被动]

  受到伤害时，消耗1张紫卡，将本卡效果视为「免疫本次伤害」。
  规避成功后，抽取1张基本牌。
```

### 基本牌范例
```
击敌 [基本牌, 白]

  对目标造成1点物理伤害。
```

## 常见问题

**Q: 添加新卡牌的步骤？**
1. 在 `cards/` 创建 `ID-卡名/` 文件夹
2. 在文件夹内创建 `card.dz`（DZ 语法）
3. 在 `_distribution.json` 添加配比
4. `cargo test` 验证解析通过

**Q: 卡牌效果不生效？**
- 检查 DZ 语法是否符合本指南的格式
- 运行 `cargo test` 查看解析器报错
- 检查效果文本是否包含标准谓语动词（消耗/获得/造成等）

**Q: 批量导出卡面？**
参考 `BatchOutputPort` 的实现，调用 `BatchRenderer` 即可将全部卡牌渲染为 SVG。
