## 三、阶段一：前端品质提升（评级 3.5 → 4.3）

### 1.1 CSS 模块化（P1，Pro）

**当前**：所有页面全 inline `React.CSSProperties` → 不可维护、不可主题化、重复代码多。  
**目标**：迁移至 CSS Modules（`.module.css`），定义设计主题 token。

```
任务拆解：
  1. 定义 token 主题变量文件 (colors/spacing/typography/shadow)
  2. 提取公共组件样式为 CSS Module (btnStyle/cardItemStyle/inputStyle/overlayStyle)
  3. 每个页面逐页迁移：
     ├─ App.tsx          → App.module.css
     ├─ CardLibraryPage  → CardLibraryPage.module.css
     ├─ CardEditorPage   → CardEditorPage.module.css
     ├─ BatchExportPage  → BatchExportPage.module.css
     ├─ DuelPage         → DuelPage.module.css
     └─ SettingsPage     → SettingsPage.module.css  (保留部分)
  4. 实现 light/dark 双主题切换（通过 CSS 变量）
```

**验收标准**：切换主题时所有页面联动变色，无编译错误。

## 五、阶段三：文档与 CI/CD（评级 3.0 → 4.0）

### 3.1 GitHub Actions 自动构建（P1，Pro）

**当前**：只有 `justfile`。  
**目标**：每次 push 自动跑 `cargo test && npx tauri build`，发布 Release 自动上传产物。

```yaml
# .github/workflows/release.yml 概要
on:
  push:
    tags: ['v*']
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v4
      - run: rustup toolchain install stable
      - run: cargo test --workspace

  build:
    needs: test
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm install
      - run: npx tauri build
      - uses: actions/upload-artifact@v4
        with:
          path: target/release/bundle/
```

**验收标准**：GitHub PR 自动触发测试，tag push 自动构建并上传 msi/exe。
