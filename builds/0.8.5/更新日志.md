# CardMaker 更新日志

## v0.8.5（2026-05-29）— 卡面字体自定义

### 新增
- 卡面字体自定义：Step2 基本信息新增「卡面样式」区域
  - 字体选择：微软雅黑 / 宋体 / 黑体 / 楷体 / 仿宋 / 隶书 / 行楷 / 无衬线 / 衬线体（共 9 种）
  - 字号：10~48px 自由调节
  - 文字颜色：ColorPicker 任意取色
  - 卡牌名称、技能名称、效果描述、属性面板全部使用自定义样式
- 字体信息写入 CardPreview 实时预览
- 字体/字号/颜色存入 `ICard.cardFontFamily` / `cardFontSize` / `cardTextColor`，随 JSON 导出
