# CardMaker 更新日志

## v0.9.0（2026-05-30）— 五段式编辑器 + 全本地化 + 语法校验

### 架构升级
- 版本文件夹独立：0.9.0 继承 0.8.5 全部代码（robocopy 排除 dist/node_modules/.git）
- 全链路版本号同步：`package.json` / `Cargo.toml` / `tauri.conf.json` / 快捷方式 → 统一 0.9.0

### 新增：应用设置面板（Step 1-2）
- 标题栏齿轮图标入口，独立 Settings 页面（583 行）
- 四大分区：产出路径 / 卡面视觉 / 游戏常量 / 编辑器偏好
- localStorage 存储 + JSON 导入/导出 + 一键恢复出厂
- `IAppSettings` 接口重构为结构化嵌套类型
- `IQualityColorScheme` 接口 + 四品质配色方案 ColorPicker
- `configManager` 全量重写为 `get(section, key)` / `set(section, key, value)` API

### 新增：五段式效果编辑器（Step 3）
- `IFiveSegmentEffect` 接口：层级(L1/L2/L3) / 条件 / 主语(15选1) / 谓语(28选1) / 宾语 / 备注
- `ISkill.fiveSegmentEffects` 字段兼容旧 `effects` 数组
- 模板文件 `templates/fiveSegment.ts`（299 行）：10 条件 / 12 宾语 / 4 备注模板 + 8 组谓语分组
- `Step3_EffectEdit.tsx` 重写（1298 行）：
  - 五段式 Table 模式：层级 Select / 条件模板+AutoComplete / 主语 Select / 谓语 Select(分组) / 宾语模板+自由输入 / 备注 Input+分类 Select / 操作按钮
  - L2/L3 行缩进 20px/40px，`#fafafa` 背景，parentId 级联删除
  - Switch 切换旧 Collapse 三面板模板模式（完整保留）
  - `generateId("fseg")` 生成行 ID，`handleApply` 写入 `fiveSegmentEffects`

### 新增：全本地化（Step 5）
- 自动备份：`configManager` 新增 `backup` / `getBackups` / `restoreFromBackup` 等 5 方法，`save()` 末尾自动触发，最多保留 5 条快照
- 词典外部化：`GRAMMAR_RULES` 从 `constants.ts` 迁出为 `data/grammar-rules.json`（8 条禁止 + 8 条自检），改为 Vite JSON import
- 批量导出：`exportCardsToJSON` / `exportCardsToMarkdown` / `downloadFile` / `batchExportAllCards`，文件名含 YYYYMMDD 日期戳

### 新增：语法校验引擎（Step 6）
- `utils/grammarValidator.ts` — `validateFiveSegmentEffects(effects)` 主函数
- 8 条禁止规则（ERROR）：F01 主语自身 vs 宾语敌方 / F02 备注含谓词 / F03 备注含条件词 / F04 备注含公式 / F05 备注含附加效果 / F06 条件栏含谓词 / F07 主语切换未拆条 / F08 子级缺父级引用
- 8 条自检规则（WARNING）：S01 {N} 占位符 / S02 {X} 占位符 / S03 空条件含子条目 / S04 非法主语 / S05 非法谓语 / S06 宾语谓语兼容 / S07 备注缺分类 / S08 超三层嵌套
- 谓词→宾语兼容映射表（28 谓词 × 5 类别）+ 去重（`effect.id | ruleId`）
- 集成到 Step3 五段式编辑器底部：红色 Error / 橙色 Warning / 绿色 Pass 三态 Alert 实时刷新

### 修复
- `validators.ts` 适配新 configManager API
- Rust 编译环境诊断与修复：robocopy 携带的旧 target 缓存含硬编码路径 `E:\CardMaker\` 导致编译失败，清理后重编译通过
- 构建产出不完整问题：手动 `vite build` 因缓存仅产出 403KB main.js（缺失 37% 代码），改用 `npx tauri build` 完整流水线产出 643KB + 正确嵌入前端
- 版本号显示不一致：`App.tsx` / `main.tsx` 通过 `package.json` 动态读取版本，确保 UI 标题与 tauri.conf.json 窗口标题同步

## v0.8.5（2026-05-29）— 卡面字体自定义

### 新增
- 卡面字体自定义：Step2 基本信息新增「卡面样式」区域
  - 字体选择：微软雅黑 / 宋体 / 黑体 / 楷体 / 仿宋 / 隶书 / 行楷 / 无衬线 / 衬线体（共 9 种）
  - 字号：10~48px 自由调节
  - 文字颜色：ColorPicker 任意取色
  - 卡牌名称、技能名称、效果描述、属性面板全部使用自定义样式
- 字体信息写入 CardPreview 实时预览
- 字体/字号/颜色存入 `ICard.cardFontFamily` / `cardFontSize` / `cardTextColor`，随 JSON 导出
