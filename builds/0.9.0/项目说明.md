# CardMaker — 《对峙》卡牌编辑器 v0.9.0

## 快速了解

CardMaker 是专为策略卡牌游戏《对峙》设计的桌面编辑器。设计师通过四步向导 UI 配置卡牌、技能、效果，无需写一行 JSON。导出支持 JSON 和 PNG 两种格式，两者可双向互导。

- 技术栈：Tauri v2 + React 19 + TypeScript + Zustand + Ant Design 6（前端），Rust 1.96 + Serde（后端）
- 25 个效果模板 · 12 个条件模板 · 8 个消耗模板 · 17 个枚举 · 23 个接口
- 当前版本：0.9.0（2026-05-30）

## 设计原则

1. **原子化解耦**：每个效果/条件/消耗是独立 TypeScript 文件，新增类型只需新增文件 + 注册，不修改现有代码。
2. **枚举驱动**：17 个枚举消除全部魔法字符串。
3. **自然语言预览**：`exporters.ts` 把结构化数据实时翻译成中文描述，所见即所得。
4. **版本独立**：每个版本文件夹是完整自包含项目，可直接封包交付。

## v0.9.0 新增 — 应用设置面板 + 五段式效果编辑器重构

### 设置面板
- 标题栏齿轮图标入口，独立 Settings 页面
- 四分区：产出路径 / 卡面视觉 / 游戏常量 / 编辑器偏好
- 品质配色方案 ColorPicker 可视化编辑
- localStorage 存储 + JSON 导入/导出 + 一键恢复出厂

### 架构升级
- `IAppSettings` 重构为结构化嵌套类型（`outputPaths`/`cardVisuals`/`gameConstants`/`editorPreferences`）
- `configManager` 全量重写，基于 `get(section, key)` / `set(section, key, value)` API
- 新增 `IQualityColorScheme` 接口

## v0.8.5 新增 — 卡面字体自定义

在 Step2 基本信息中添加「卡面样式」区域，支持：
- **字体**：微软雅黑 / 宋体 / 黑体 / 楷体 / 仿宋 / 隶书 / 行楷 / 无衬线 / 衬线体
- **字号**：10~48px
- **文字颜色**：自由取色（hex）

三者在 CardPreview 预览中实时生效，卡牌名称、技能文本、属性面板均使用自定义样式。字体信息随卡牌数据导出到 JSON。

## 扩展指南

新增效果模板：写 `effect-xxx.ts` → `EffectType` 枚举加值 → `templates/index.ts` 注册 → `exporters.ts` 加自然语言 → `validators.ts` 加校验。三步之内闭环，不碰其他文件。
