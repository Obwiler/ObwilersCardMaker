# CardMaker 更新日志

## v0.8.3（2026-05-29）

### Bug 修复
- 修复技能配置未持久化的根因 Bug：Step3_EffectEdit.tsx 的"下一步"按钮直接调用 `onNext()` 跳转，跳过了 `handleApply()` 将 pendingSkills 写入 Zustand store。修复为串联 `handleApply()` 后再 `onNext()`，确保技能配置完整保存。
- 标题栏精简：从"CardMaker - 《对峙》卡牌编辑器 v0.6.3"改为"CardMaker v0.8.3"。
- 版本号统一：`package.json`、`Cargo.toml`、`tauri.conf.json` 均同步为 0.8.3。

---

## v0.8.2（2026-05-29）

### 新增功能
- PNG 导出自定义保存路径：Rust 后端新增 `save_card_image` 命令，使用 base64 crate 解码前端传递的图像数据，通过二进制写入磁盘。前端改用 Tauri `save()` 对话框选择保存位置。

### 技术变更
- Rust 依赖新增 `base64 = "0.22"`
- `save_card_image` 注册到 `tauri::generate_handler`
- 桌面快捷方式指向 `E:\CardMaker\src-tauri\target\release\cardmaker.exe`

## v0.8.0（2026-05-29）

## v0.6.3（2026-05-29）

### 项目初始化
- CardMaker 项目搭建完成：Tauri v2 + React 19 + TypeScript。
- 实现 17 个核心枚举、23 个接口、24 个效果模板、12 个条件模板、8 个消耗模板。
- Zustand 状态管理、四步向导 UI（选择卡牌类型 → 基本信息 → 技能效果配置 → 导出）。
- 多轮 Bug 修复：闪退、写入失败、预览不同步、条件/效果添加无反馈。
- 全量代码审计：发现并修复 6 项严重问题、30 项重要问题。

### 技术架构
- 前端：React 19 + TypeScript 5.5 + Vite 6 + Zustand 5 + Ant Design 6
- 后端：Rust 1.96 + Tauri v2 + Serde
- 四个 Tauri Command：`greet`、`save_card_data`、`load_card_data`、`save_card_image`（v0.8.2 新增）
- 目标选择引擎：过滤器链 + 排序器模块化设计
- 自然语言预览生成器
