> v2.0 — 基于新语法体系完全重写。
> 五段式格式：`条件 → 主 → 谓 → 宾 → 备注`
> 递归嵌套：任何槽位可展开为子五段式，用 `[标签引用]` + 独立定义块表示。
> 标签机制：15 个标签，卡牌效果中直接引用标签名。

## 第一章：游戏语法体系总览

《对峙》v0.6.3 的所有卡牌效果统一采用**五段式语法**描述。本章介绍语法体系的四大核心机制。

### 1.1 五段式基础格式

任何卡牌效果均可且必须映射为以下不可分割的最小语义单元：

```
条件 → 主 → 谓 → 宾 → 备注
```

| 字段 | 含义 | 允许内容 | 禁止内容 |
|------|------|---------|---------|
| **条件** | 触发条件/使用前提 | 时机、消耗、状态判断、阈值、宣言 | — |
| **主** | 效果执行者 | 自身 / 目标 / 装备者 / 伤害来源 / 攻击者 / 指定单位 / 其他玩家 / 敌方 等 | — |
| **谓** | 核心动作（单一动词） | 造成、恢复、获得、弃置、抽取、免疫、消耗、放置、移除、判定、积累、补充、抵消、增加、降低、扣除、赋予、限制、无效化、封锁、重置、淘汰、视为、存储、重排、更换、执行、强制使、翻牌堆顶、复制、选择保留、放回 等 | — |
| **宾** | 动作对象及数值 | 伤害点数、生命值、卡牌数量、标记类型与数量、状态描述、**标签引用** | **禁止含动词** |
| **备注** | 额外说明 | **仅限四类**：频率限制 / 上限限制 / 互斥关系 / 扩展说明 | **禁止**条件判断、分支效果、数值计算、附加效果 |

> 条件栏无条件时写 `—`。主语和谓语不可省略。

### 1.2 递归嵌套规则

任何槽位（条件 / 主 / 谓 / 宾 / 备注）都可以被展开为子五段式。嵌套关系是**向下定义**——上级元素若是复合概念，在下级用完整五段式解释。

嵌套表示方式：用 `[标签引用]` 引用已定义的抽象块，在独立定义块中展开。定义块使用 `[标签名]定义：` 标记，后跟子五段式。

**示例——浮光（武学）完整嵌套展开：**

```
浮光技能1：受到伤害时 → 自身 → 执行 → [韬光养晦] → —

[韬光养晦]定义：
| — | 自身 | 消耗 | 1张紫卡 | — |
| — | 该紫卡效果 | 视为 | 「免疫本次伤害」 | — |

浮光技能2：规避成功后 → 自身 → 抽取 → 1张基本牌 | —
```

嵌套规则：
- 一级效果通过 `执行 → [标签名]` 引用子块
- 子块内部仍然是完整五段式，可继续嵌套
- 嵌套不限制深度，但实际设计建议不超过 3 层

### 1.3 标签引用机制

凡卡牌效果匹配已确认的 15 个标签模板之一，在语法中**直接引用标签名**，不再逐字展开。标签定义详见第八章及《标签字典.md》。

引用方式：
```
条件 → 自身 → 执行 → [标签名] → —
```

被引用标签在独立定义块中展开。定义块的五段式条目属于标签本身，**不占用卡牌本身的层级编号**。

### 1.4 优先级与冲突机制

#### 1.4.1 备注字段禁令（最高优先级）

备注栏**只允许**四类内容。任何超出范围的内容必须提升至独立条目：

| 允许类型 | 示例 | 禁止类型 | 正确处理 |
|---------|------|---------|---------|
| 频率限制 | 每回合限1次、每大回合1次 | 条件判断 | 拆为独立 L2 条目 |
| 上限限制 | 最多4张、上限2层 | 分支效果 | 拆为独立条目 |
| 互斥关系 | 与轻浮互斥 | 数值计算 | 提升至条件栏 |
| 扩展说明 | 不消耗攻击次数 | 附加效果 | 拆为独立条目 |

#### 1.4.2 宾语栏禁令

宾语栏**不得包含动词**。动词必须留在谓语栏。

| 违规示例 | 修正 |
|---------|------|
| 宾：`目标弃置1张手牌` | 谓：`强制目标弃置`，宾：`1张手牌` |
| 宾：`伤害生效` | 谓：`强制使`，宾：`该伤害生效` |
| 宾：`为副职业` | 谓：`更换为`，宾：`副职业身份` |

#### 1.4.3 主语切换规则

主语（主栏）发生变化时必须**新建独立条目**，不得在同一行内隐式切换主语。

```
错误：受到伤害后 → 自身 → 对伤害来源造成1点伤害并抽1张牌
      （同一行内含两种主语的动作）

正确：
L1：受到伤害后 → 自身 → 造成 → 伤害来源1点伤害 → —
L2：触发L1后 → 自身 → 抽取 → 1张牌 → —
```

## 第二章：五段式语法详解

### 2.1 条件栏

**定义**：效果的触发条件或使用前提。

**填写规则**：
- 无条件触发时写 `—`
- 被动常驻效果写 `—`（但备注应注明"常驻"）
- 复合条件用逗号分隔，如 `消耗2技力，宣言非橙色品质`
- 复杂计算公式（如 `X=回合内触发次数`）必须完整写入条件栏

**允许内容**：
| 类别 | 模板关键词 |
|------|----------|
| 消耗 | 消耗{N}点技力、消耗{N}点生命、弃置{N}张手牌、消耗{N}个「{X}」标记 |
| 触发 | 获得{X}时、使用{X}后、受到伤害时/后、造成伤害后、回合开始时/结束时 |
| 状态 | 目标有/无{X}、目标生命＜{N}、{属性}≥{N}、手牌≤{N}、持有{X} |
| 限制 | 每回合{N}次、首次、一次性、被动 |

**禁止**：在条件栏隐式写分支效果（如 `若A则B，否则C`），必须拆条。

### 2.2 主语栏

**定义**：效果的执行者或来源。

**填写规则**：
- 主语不可省略。即使主语为"自身"，也必须显式写出
- 卡牌效果可拟人化为主语（如 `该紫卡效果`），使嵌套语义清晰
- 主语栏只能有一个执行者

**允许内容**：详见第四章主语词条库（14 种主语类型）。

### 2.3 谓语栏

**定义**：效果的核心动作。

**填写规则**：
- 每条效果**只允许一个核心谓语动词**
- 严格区分近义词：`造成` vs `附加`、`弃置` vs `消耗`、`视为` vs `当作`
- 复合动作（如"造成伤害并抽牌"）拆为多条
- 标签引用时，谓语写 `执行`，宾语写 `[标签名]`

**允许内容**：详见第五章谓语词条库。

### 2.4 宾语栏

**定义**：动作的对象及数量/类型。

**填写规则**：
- 宾语只含名词、数值、描述、标记名、卡牌名、标签引用
- **绝对禁止含动词**（参见 1.4.2）
- 数值公式在宾语中完整写出，如 `（消耗技力-1）点伤害`
- 标签引用写法：`[标签名]`

**允许内容**：详见第六章宾语词条库。

### 2.5 备注栏

**定义**：对效果的额外说明，严格限定为四类。

**四类合法内容**：
| 类别 | 说明 | 示例 |
|------|------|------|
| 频率限制 | 触发/使用的频次 | 每回合限1次、每大回合1次、每配方每回合1次 |
| 上限限制 | 数值/数量的硬上限 | 最多4张、上限2层、最多累计-2 |
| 互斥关系 | 与其他卡的互斥 | 与轻浮互斥、与云龙互斥 |
| 扩展说明 | 必要的效果补充 | 不消耗攻击次数、常驻、可对自身使用、弃置的牌归入构筑牌弃牌堆 |

**禁止内容及处理**：详见 1.4.1 备注字段禁令。

### 2.6 层级编号规则

当一张卡牌有多个独立效果时，按层级编号：

| 层级 | 含义 | 标准 |
|------|------|------|
| **L1** | 主条目，核心/第一效果 | 打出卡牌的首个效果 |
| **L2** | 二级效果，L1 触发后的连锁 | 造成伤害后的附加效果 |
| **L3** | 三级效果，L2 触发后的连锁 | 附加效果之外的第三段 |

规则：
- 每条 L1/L2/L3 独立构成完整五段式
- 标签定义块内的条目**不占用卡牌本身的层级编号**，有独立的内部编号（如 A/B/C）
- 主语切换时自动升级为新条目

### 2.7 省略规则

| 情况 | 写法 |
|------|------|
| 无条件触发 | 条件栏写 `—` |
| 无备注 | 备注栏写 `—` |
| 主语为自身 | **不可省略**，必须写 `自身` |
| 谓语 | **不可省略** |

## 第四章：主语词条库

以下穷举《对峙》v0.6.3 全部卡牌中出现的 14 种主语类型。

| # | 主语 | 语义说明 | 典型卡牌 |
|---|------|---------|---------|
| 1 | `自身` | 卡牌持有者 / 效果发起者 | 绝大多数卡牌（击敌、疗伤、聚气等） |
| 2 | `目标` | 效果指向的单个对象 | 重锤、巨弩、医师 |
| 3 | `装备者` | 装备此卡的角色（同自身，用于装备语境） | —（DIY 可用） |
| 4 | `伤害来源` | 造成本次伤害的单位 | 荆棘 |
| 5 | `攻击者` | 发起攻击的单位 | 黯然 |
| 6 | `所有玩家` | 全场所有参与者 | —（DIY 可用） |
| 7 | `指定单位` | 由玩家自由指定的单个对象 | 寻岚、崩山、纯洁 |
| 8 | `其他玩家` | 除自身外的任意一名玩家 | 谋士、军师 |
| 9 | `其他单位` | 除自身外的任意游戏单位 | 止波 |

| 禁止类型 | 说明 | 错误示例 | 正确处理 |

### 8.2 递归嵌套完整示例：浮光

浮光是递归嵌套的最典型案例——一级效果通过 `执行 → [韬光养晦]` 引用标签，标签内部又包含主语切换（自身 → 紫卡效果）。

**卡牌信息**：浮光 / 武学 / 被动 / 上限 2 张 / 互斥：—

**完整语法条目**：

```
浮光技能1：受到伤害时 → 自身 → 执行 → [韬光养晦] → —

[韬光养晦]定义：
| # | 条件 | 主 | 谓 | 宾 | 备注 |
|---|---|---|---|---|---|
| A | — | 自身 | 消耗 | 1张紫卡 | — |
| B | — | 该紫卡效果 | 视为 | 「免疫本次伤害」 | — |

浮光技能2：规避成功后 → 自身 → 抽取 → 1张基本牌 → —
```

**嵌套层次解析**：

```
Level 0（卡牌级）:
  技能1 ──执行──▶ [韬光养晦]（标签引用）
  技能2 ──抽取──▶ 1张基本牌（直接效果）

Level 1（标签定义块 [韬光养晦]）:
  子效果A ──消耗──▶ 1张紫卡（资源支付）
  子效果B ──视为──▶ 「免疫本次伤害」（主语切换：自身→紫卡效果）
```

关键要点：
- 技能1 只有一层引用（`执行 → [韬光养晦]`），不展开细节
- 所有细节在 `[韬光养晦]定义：` 块中完整展开
- 子效果 B 的主语是 `该紫卡效果`（将卡牌效果拟人化）
- 技能2 与技能1 同级，共享触发链（规避成功 → 抽牌）
- 标签内部条目（A/B）不占用卡牌本身的 L1/L2/L3 编号体系

## 第九章：语法组装规则

### 9.1 基本组装流程

设计一张 DIY 卡牌时，按以下步骤将创意转化为语法条目：

**步骤一：分解效果**
将卡牌的自然语言描述拆解为原子效果单元。判断标准：
- 每个原子效果有**独立的触发时机**或**独立的结果**
- 若效果包含"并/同时/且/然后"，大概率应拆为多条

**步骤二：确定层级**
按因果关系排序：核心效果 → L1，触发后的连锁 → L2，再连锁 → L3。

**步骤三：逐条填充五要素**
按 `条件 → 主语 → 谓语 → 宾语 → 备注` 模板填充每条。

**步骤四：自检**
- 宾语栏是否不含动词？
- 备注栏是否仅含四类合法内容？
- 主语切换是否已独立成条？
- 条件判断是否已提升至条件栏或拆条？

### 9.2 禁止组合规则

| 禁止规则 | 说明 | 正确做法 |
|---------|------|---------|
| 宾语含动词 | 宾语只能是被操作对象 | 动词移入谓语栏 |
| 备注含条件判断 | `目标有X则Y` 不能放备注 | 拆为 L2，条件栏写 `目标有X时` |
| 备注含分支效果 | `否则Z` 不能放备注 | 拆为独立条，条件写判定条件的否定 |
| 备注含附加效果 | 额外独立效果不能塞备注 | 拆为独立条目 |
| 备注含数值公式 | `消耗=X` 不能放备注 | 提升至条件栏或宾语栏 |
| 主语隐式切换 | 一条内不能换执行者 | 新建条目 |
| 谓宾混叠 | 谓语和宾语不能混为一体 | 严格分离 |
| 同一条目多谓语 | 一条只允许一个核心谓语 | 拆为多条 |

### 9.3 DIY 设计模板

#### 模板 A：简单效果（单条，无连锁）

```
消耗{N}点技力 → 自身 → 造成 → 目标{N}点{X}伤害 → 每回合限1次
```

占位符说明：`{N}` 数值，`{X}` 伤害类型（物理/法术/真实）。

#### 模板 B：触发型被动（单条，无连锁）

```
{X}时 → 自身 → {谓语} → {宾语} → 每回合{N}次
```

#### 模板 C：二元判断效果（2 条）

```
L1：消耗{N}点{X}，令目标判定 → 自身 → {谓语A} → {宾语A}（判定成功） → 每回合限1次
L2：判定失败时 → 自身 → {谓语B} → {宾语B} → —
```

#### 模板 D：连锁效果（3 条）

```
L1：{条件1} → 自身 → {谓语1} → {宾语1} → {备注1}
L2：{条件2}（L1 触发后） → 自身 → {谓语2} → {宾语2} → {备注2}
L3：{条件3}（L2 触发后） → 自身 → {谓语3} → {宾语3} → {备注3}
```

#### 模板 E：标签引用型（嵌套效果）

```
L1：{条件} → 自身 → 执行 → [{标签名}] → {备注}

[{标签名}]定义：
| A | {子条件A} | {主语A} | {谓语A} | {宾语A} | {备注A} |
| B | {子条件B} | {主语B} | {谓语B} | {宾语B} | {备注B} |
```

### 9.4 完整 DIY 设计示例

#### 示例 1：新武学「雷击」

自然语言：「消耗 2 点技力，对目标造成 3 点法术伤害。如果目标有护甲，额外造成 1 点真实伤害。每回合限 1 次。」

语法分解：
```
L1：消耗2点技力 → 自身 → 造成 → 目标3点法术伤害 → 每回合限1次
L2：目标有护甲时（同上消耗） → 自身 → 额外附加 → 1点真实伤害 → —
```

#### 示例 2：新甲胄「铁壁」

自然语言：「每次受到物理伤害后获得 1 点护甲。护甲达到 4 点时，下一次造成的物理伤害 +2。」

语法分解：
```
L1：受到物理伤害后 → 自身 → 获得 → 1点护甲 → —
L2：护甲≥4时 → 自身 → 增加 → 下一次物理伤害+2 → —
```

#### 示例 3：新术法「灵魂链接」

自然语言：「消耗 3 点技力，锁定 2 个单位。你对其中一个造成的伤害，另一个也受到等量法术伤害。每大回合 1 次。」

语法分解：
```
L1：消耗3点技力 → 自身 → 锁定 → 两个单位 → 每大回合1次
L2：对锁定单位之一造成伤害后 → 自身 → 造成 → 另一单位等量法术伤害 → —
```
