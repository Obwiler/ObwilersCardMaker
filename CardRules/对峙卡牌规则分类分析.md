# 《对峙》卡牌规则分类分析

> 基于新语法体系完全重写。语法版本：五段式 + 递归嵌套 + 标签引用。
> 标签定义见《标签字典.md》，语法规范见《对峙规则语法规范.md》。

## 一、设计概要

### 1.1 总体构成

| 层级 | 类型 | 数量 | 说明 |
|------|------|------|------|
| 身份层 | 阵营卡 | 5 | 开局绑定，决定底层机制与专属标记 |
| 身份层 | 职业卡 | 12 | 每回合可用的主动技能 |
| 装备层 | 构筑卡 | 40 | 兵刃5 + 宝器5 + 甲胄10 + 武学10 + 术法10 |
| 操作层 | 基本牌 | 100 | 白50 + 蓝25 + 紫20 + 橙5 |
| 状态层 | 标记 | 9种 | 阵营5 + 职业3 + 构筑1 |
| **合计** | | **157张 + 9种标记** | |

### 1.2 语法体系版本

| 特性 | 说明 |
|------|------|
| **基础格式** | 五段式：`条件 → 主 → 谓 → 宾 → 备注` |
| **递归嵌套** | 任何槽位可展开为子五段式，用 `[标签名]` 引用 + 独立定义块展开 |
| **标签引用** | 15个已确认标签，卡牌直接引用标签名，定义块使用 `[标签名]定义：` 标记 |
| **备注四禁令** | 仅允许：频率限制、上限限制、互斥关系、扩展说明 |
| **宾语禁令** | 宾语栏禁止含动词，动词一律归入谓语栏 |
| **主语切换** | 主语变化即拆新条目 |

| # | 标记名 | 标记属性 | 来源卡牌 | 流转模式 |
|---|--------|---------|---------|---------|
| 1 | 仁心 | 累计消耗型 | 儒家（阵营） | 获得白/紫牌积累 → 消耗换技力/抽牌/回血 |

| 6 | 零件 | 累计消耗型 | 工师（职业） | 受减护甲效果获得 → 消耗换技力/护甲 |

> 共9种标记。标记是**token记号**——附着于单位的不可见手牌指示物，与标签（技能模板）严格区分。标记不可放入手牌、不占牌库位、不被对手直接弃置。

### 1.5 标记 vs 标签（核心区分）

| 维度 | 标记（Token） | 标签（Tag） |
|------|-------------|-----------|
| 本质 | 可计数的量化资源指示物 | 可复用的技能模板/机制块 |
| 操作方式 | 积累/消耗/放置/移除/引爆 | 引用/执行/展开为子五段式 |
| 在语法中的位置 | 宾语栏（如 `1个「仁心」标记`） | 谓语栏 `执行 → [标签名]` + 独立定义块 |
| 是否占手牌位 | 否（不可见指示物） | —（语法概念，非实体） |
| 可移除性 | 除障/圣愈术可移除 | 不可移除（语法结构） |
| 相同点 | 均可跨卡牌引用 | — |

## 二、按来源分类

### 2.1 阵营卡（5张）

#### 2.1.1 儒家

| 属性 | 数值 |
|------|------|
| 生命 | 8 |
| 护甲 | 2 |
| 技力 | 4 |

**核心技能：仁怀**

- 标记体系：产生/消耗 `仁心` 标记
- 定位：续航 + 过牌
- 关键效果：获得白/紫牌积仁心（上限3/回合）→ 仁心换技力/抽牌/回血，回合结束仁心≥1自动抽1

**卡牌清单：**

| 卡牌 | 关键效果摘要（五段式简写） |
|------|------------------------|
| 儒家 | 获得白/紫基本牌时 → 自身 → 积累 → 1个「仁心」→ 每回合最多3个；消耗1「仁心」→ 自身 → 恢复 → 1技力；消耗1「仁心」→ 自身 → 抽取 → 1张牌；回合结束「仁心」≥1 → 自身 → 抽取 → 1张牌 |

|------|------|

| 护甲 | 2 |
