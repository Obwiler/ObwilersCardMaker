# DZ IDE 辅助系统规范

> 本文件定义卡牌编辑器的自动补全、语法高亮、实时校验规则。
> 目标：让编辑器像代码 IDE 一样智能辅助设计师书写卡牌效果。

---

## 第一章：Token 类型与语法高亮

### 1.1 Token 分类

| Token | 正则/匹配 | 颜色 | 示例 |
|-------|----------|------|------|
| CARD_NAME | 行首到 `[` 或 `:` 之前 | 金色加粗 | `浮光` |
| TYPE_TAG | `[]` 内的类型名 | 绿色 | `[武学, 被动, 上限2]` |
| COND_KEYWORD | 条件行（以`:`结尾） | 青色 | `受到伤害时:` |
| BRANCH | `?` 开头的行 | 黄色 | `? 判定牌为蓝卡:` |
| COST_ARROW | `:` 开头的消耗行 | 橙色 | `: 消耗2技力 →` |
| OPTION | `·` 开头的行 | 紫色 | `· 消耗1材料+弃1手牌 →` |
| PREDICATE | 谓语动词 | 蓝色 | `造成` `恢复` `获得` |
| MARK | `「」` 包裹的文本 | 品红 | `「仁心」` |
| CARD_REF | `""` 包裹的卡牌引用 | 黄绿 | `"击敌"卡` |
| REMARK | `[]` 行尾备注 | 灰色 | `[每回合限1次]` |
| SUBJECT | 显式主语 | 橙红 | `对目标` `攻击者` |
| VALUE | 数值 | 白色高亮 | `1点物理伤害` |

### 1.2 高亮范围

```
卡牌名 [类型, 属性]:     ← CARD_NAME + TYPE_TAG
  触发条件:               ← COND_KEYWORD
    谓语 宾语 [备注]      ← PREDICATE + VALUE + REMARK
    ? 分支条件:            ← BRANCH
      谓语 宾语
    : 消耗 → 效果         ← COST_ARROW
    · 选项 → 效果 [备注]  ← OPTION
```

## 第二章：自动补全触发规则

### 2.1 补全触发时机

| 光标位置 | 触发条件 | 补全内容 |
|---------|---------|---------|
| 行首空行 | 缩进层级1 | 条件词列表（`受到伤害时:` `回合开始时:` 等 30+ 选项） |
| 行首空行 | 缩进层级1 | 或谓语动词列表（无条件效果） |
| 条件行尾 | 输入 `:` | 无补全，等待下一行 |
| 效果行首 | 缩进层级≥1 | 谓语动词列表（`造成` `恢复` `获得` 等 40+ 选项） |
| 谓语后 | 空格后 | 宾语类型推荐（根据谓语语义推荐合法宾语） |
| `「` | 输入 `「` | 标记名列表（`仁心` `自然` `法令` 等 9 种） |
| `? ` | 输入 `? ` | 条件词列表（分支条件） |
| `· ` | 输入 `· ` | 无补全（自由文本） |
| `:` (消耗行) | 输入 `: ` | 消耗动词列表（`消耗` `弃置` `耗`） |
| `[` (备注) | 行尾输入 `[` | 四类备注列表 |
| `"` | 输入 `"` | 卡牌名/技能名列表 |

### 2.2 语义感知补全

补全系统根据上下文智能过滤：

```
例子 1: 输入"受到" → 条件行 → 触发类补全：
        "受到伤害时:" "受到伤害后:"

例子 2: 输入"获得" → 效果行 → 宾语推荐：
        "1个「X」标记" "1点护甲" "1点技力" "N张基本牌"

例子 3: 输入"对" → 主语切换 → 主语列表：
        "对目标" "对1单位" "对伤害来源"

例子 4: 输入"「" → 标记引用 → 标记名列表：
        已有标记则优先显示；未定义标记显示警告色
```

### 2.3 补全优先级

```
1. 精确匹配（输入完全匹配某词条）> 
2. 前缀匹配（输入是某词条前缀）> 
3. 子串匹配（输入在词条中出现）> 
4. 语义相关（同类型其他词条）
```

## 第三章：实时校验规则

### 3.1 错误级别

| 级别 | 图标 | 含义 |
|------|------|------|
| Error 🔴 | 红色波浪线 | 语法错误，解析失败 |
| Warning 🟡 | 黄色波浪线 | 可疑但可解析（未知标记名、拼写疑是错误） |
| Info 🔵 | 蓝色虚线 | 提示（效果过于简单等） |

### 3.2 校验规则清单

| # | 规则 | 级别 | 错误信息 |
|---|------|------|---------|
| 1 | 宾语栏含动词 | 🔴 | 宾语栏不得包含动词，请将动词移至谓语栏 |
| 2 | 备注含条件判断 | 🔴 | 备注仅限四类内容，条件判断请使用 `? 条件:` 分支 |
| 3 | 备注含分支效果 | 🔴 | 备注仅限四类内容，分支效果请拆为独立条目 |
| 4 | 一行内主语切换 | 🔴 | 主语切换请拆为独立行 |
| 5 | 缩进层级跳跃 | 🔴 | 缩进层级不得跳跃（从2空格直接到6空格） |
| 6 | 未知谓语动词 | 🟡 | "{word}" 不在谓语词典中，检查是否拼写错误 |
| 7 | 未知标记名 | 🟡 | 「{name}」未在任何标记定义中找到 |
| 8 | 未知条件词 | 🟡 | 条件词 "{cond}" 不在条件词词典中 |
| 9 | 卡牌头缺类型标记 | 🔴 | 卡牌定义缺少类型标记 [type] |
| 10 | 宾语缺失 | 🔴 | 谓语"{pred}"需要宾语 |
| 11 | 别名不匹配 | 🔵 | 此标记名有别名，建议使用标准名称 "{standard}" |

### 3.3 校验时机

```
即时校验: 每次按键后 300ms 防抖
保存校验: 保存文件时全量校验
构建校验: 导出卡面时全量校验 + 渲染预览
```

## 第四章：编辑辅助功能

### 4.1 快速插入

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+C` | 插入条件行模板 |
| `Ctrl+Shift+E` | 插入效果行模板 |
| `Ctrl+Shift+M` | 插入标记引用 |
| `Ctrl+Space` | 触发自动补全 |
| `Ctrl+/` | 注释/取消注释当前行 |

### 4.2 词条速查面板

```
┌─ 词条速查 ───────────────────┐
│ [条件] [谓语] [宾语] [备注]    │
│                               │
│ 消耗类:                       │
│  消耗N点技力                   │
│  消耗N点生命                   │
│  弃置N张手牌                   │
│  ...                          │
│                               │
│ 触发类:                       │
│  受到伤害时                    │
│  受到伤害后                    │
│  回合开始时                    │
│  ...                          │
└───────────────────────────────┘
```

## 第五章：错误信息规范

### 5.1 错误信息格式

```
[级别] [行号:列号] 错误描述
建议: 修复建议
```

### 5.2 常见错误示例

```
🔴 [3:5] 宾语栏不得包含动词
  3 | 消耗 目标弃置1张手牌
          ^^^^^^
建议: 应写为 "强制目标弃置 1张手牌"，谓语为"强制目标弃置"

🟡 [7:12] 未知标记名
  7 | 消耗 1个「人仁心」标记
                 ^^^^^^
建议: 合法标记名包括: 仁心, 自然, 法令, 坚守, 谋略, 零件, 蓄力, 材料, 噬魂
