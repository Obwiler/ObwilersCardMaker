# DZ 语法体系 — 总览

> DZ = 对峙。本语法覆盖原始套全部 78 种卡牌 + 9 种标记。拓展包卡牌沿用同一语法体系。

---

## 一、卡牌体系

```
原始套（本辞典收录）
├── 阵营卡  5 种
├── 职业卡 12 种
├── 构筑卡 40 种（兵刃5+宝器5+甲胄10+武学10+术法10）
├── 基本牌 21 种（白9+蓝6+紫4+橙2）
└── 标记    9 种

拓展包（未来加入）
├── 新构筑卡（编号从 GZ41 起）
├── 新基本牌（编号从 JB22 起）
└── 新标记   （编号从 BJ10 起）
```

---

## 二、五大类声明行

| 大类 | 声明行 | 规则 |
|------|--------|------|
| 阵营卡 | `卡名 [阵营, 生命N, 护甲N, 技力N]` | 有且仅有一个核心技能 |
| 职业卡 | `卡名 [职业]` | 消耗写在效果中 |
| 构筑卡 | `卡名 [子类型, 主动/被动]` | 同名卡默认上限2张 |
| 基本牌 | `卡名 [基本牌, 白/蓝/紫/橙]` | 数量是配比数据，不写入 |
| 标记 | `标记名 [标记]` | 纯资源定义，效果由卡牌自行描述 |

## 三、核心记号与规则

| 记号 | 含义 |
|------|------|
| `条件：` | 触发条件 |
| `—` | 常驻被动 |
| `？` | 互斥判定分支（翻牌判定等，A和B不能同时发生） |
| `若` | 顺序触发的独立条件检查（可连续触发，非互斥） |
| `·` | 多选一 |
| `[ ]` | 备注约束（次数/上限/互斥/补充说明） |

**关于支付与结算（详见 `01-source-format.md` 第三章）：**

- **先支付，后生效** — 支付完成后效果才开始执行
- **消耗 = 支付，扣除/移除 = 效果** — 对自己用除障"移除"护甲是效果，不是支付
- **引用变化前的值必须明确标注「变化前」** — 如纯洁"等同于**清空前**技力值的物理伤害"
- **消耗量引用的是支付阶段实际扣除的量** — 如崩山"消耗技力减1"
- **引用变化后的值也须明确标注** — 如七伤"等同于**支付后**当前生命值"
