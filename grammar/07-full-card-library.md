# 对峙 原始套辞典

> 本文件收录《对峙》原始套全部卡牌与标记。后续推出的新卡牌作为拓展包，单独维护。
> 所有效果描述以原始五段式语法数据为准，经 DZ 语法翻译并逐卡核对。

## 壹、阵营卡

### ZY01 儒家

```
儒家 [阵营, 生命8, 护甲2, 技力4]

  核心技能：仁怀

    获得白或紫基本牌时，积累1个「仁心」标记[每回合最多3个]。

    抽到的牌指定目标并使用后，额外获得1个「仁心」标记。

    消耗1个「仁心」，恢复1点技力。

    消耗1个「仁心」，抽取1张牌。
    随后恢复1点生命。

    回合结束时若有「仁心」，抽取1张牌。
```

### ZY02 道家

```
道家 [阵营, 生命8, 护甲2, 技力4]

  核心技能：道法

    使用技能后若技力不少于3点，增加物理伤害1点[每回合1次]。

    未触发上述效果时，积累1个「自然」标记[上限2个]。

    消耗2个「自然」，增加下次伤害1点。

    回合开始时，恢复上回合消耗技力的一半（至少恢复1点）点技力。
```

### ZY03 法家

```
法家 [阵营, 生命6, 护甲2, 技力6]

  核心技能：明法

    —降低技力上限4点[永久]。

    受到伤害时消耗1点技力，抵消1点伤害[每大回合1次]。
    触发后获得1点护甲。

    回合结束时未拥有「法令」，恢复1点技力。
    随后获得1个「法令」标记。

    技力溢出时，获得1点护甲。

    拥有不少于2个「法令」时，增加法术伤害1点[永久]。
```

### ZY04 墨家

```
墨家 [阵营, 生命9, 护甲2, 技力3]

  核心技能：非攻

    受到伤害或回合结束时，获得1层「坚守」标记[上限4层]。

    拥有不少于3层「坚守」时，增加物理伤害1点。

    拥有不少于2层「坚守」时，增加技力上限1点[最多+2]。

    消耗2层「坚守」，恢复1点生命。
```

### ZY05 兵家

```
兵家 [阵营, 生命6, 护甲2, 技力3]

  核心技能：权变

    开局时，获得6个「谋略」标记[一次性]。

    弃置1张手牌，补充1个「谋略」标记[每回合1次]。

    重铸时，补充1个「谋略」标记[每回合2次]。

    拥有不少于3个「谋略」并消耗3个，更换为副职业身份。

    首次使用副职业技能时，增加物理伤害1点[永久，一次性]。

    使用副职业技能时，消耗1个「谋略」标记。
```

## 贰、职业卡

### ZY06 斥候

```
斥候 [职业]

  消耗1点技力，对目标造成1点物理伤害。
  若目标有护甲，获得1点技力，并将本次伤害转化为真实伤害。
  若目标有技力，本次伤害额外加1。
  若伤害被免疫或无效，抽取1张牌。
```

### ZY07 谋士

```
谋士 [职业]

  消耗2点技力，抽取等同于开局玩家数的基本牌。
  抽取后，弃置或分给其他玩家1张牌[二选一]。
```

### ZY08 守将

```
守将 [职业]

  消耗2点技力，赋予目标3点护甲。
  使用后至回合结束前，增加物理伤害1点。
```

### ZY09 医师

```
医师 [职业]

  消耗2点技力，恢复目标2点生命。
  目标获得1点技力。

  若以自身为目标，抽取1张牌。
```

### ZY10 工师

```
工师 [职业]

  —增加初始护甲3点[开局即生效]。

  护甲归0时，获得1点护甲[每大回合1次，最多6次]。

  受敌方减护甲效果时，获得1个「零件」标记[每回合2次]。

  消耗3个「零件」，恢复1点技力。
  消耗2个「零件」，获得1点护甲。
```

### ZY11 死士

```
死士 [职业]

  累计受伤不少于3点，增加物理伤害1点[永久，一次性]。
```

### ZY12 射手

```
射手 [职业]

  获得白或蓝卡时，存储1张为「蓄力」标记[最多4张，每回合2次]。

  使用「击敌」卡时释放「蓄力」标记，造成等同于释放张数的伤害
  [不消耗攻击次数]。
```

### ZY13 方士

```
方士 [职业]

  烈焰：
    消耗2点技力，对目标造成1点法术伤害。
    若目标有护甲，额外附加1点真实伤害。

  寒冰：
    消耗2点技力，扣除目标1点技力。
    若目标生命少于2点，额外附加1点法术伤害。
```

### ZY14 军师

```
军师 [职业]

  回合开始时若手牌不超过3张，抽取1张牌。

  其他玩家结束出卡后，消耗2点技力，抽取并立即使用目标1张手牌
  [不消耗资源]。
```

### ZY15 药师

```
药师 [职业]

  回合开始时，获得1个「材料」标记[上限4个]。

  点石成金：
    ·消耗1个「材料」并弃1张手牌，获得1点护甲[每配方每回合1次]。
    ·消耗1个「材料」并消耗1点生命，获得2点技力[每配方每回合1次]。
    ·消耗1个「材料」并消耗2点技力，抽取1张构筑卡[每配方每回合1次]。
```

### ZY16 术师

```
术师 [职业]

  每回合第1次：消耗1点技力，对目标造成1点法术伤害[每回合最多2次]。
  每回合第2次：消耗1点技力，伤害额外加1。
  触发后获得1点技力。
```

### ZY17 诡士

```
诡士 [职业]

  消耗2点技力，宣言一个非橙色品质，强制目标弃置1张该品质的手牌。

  若目标未弃出该品质手牌，抽取1张牌。

  首次使用本技能，增加法术伤害1点[永久，一次性]。
```

## 伍、标记

> 标记是附着于单位的不可见指示物。本辞典仅登记标记的名称与类型。
> 标记的产生、消耗、移除等完整效果，由使用该标记的卡牌自行描述。
> 这是因为未来任何新卡牌都可能引用已有标记，不应让标记定义绑定旧卡牌的效果。

```
BJ01  仁心 [标记]    累计消耗型
BJ02  自然 [标记]    累计消耗型
BJ03  法令 [标记]    累计阈值型（只增不减）
BJ04  坚守 [标记]    层数阈值型
BJ05  谋略 [标记]    累计消耗型
BJ06  零件 [标记]    累计消耗型
BJ07  蓄力 [标记]    存储释放型
BJ08  材料 [标记]    回合获取型
BJ09  噬魂 [标记]    叠加引爆型
```
