# DZ 渲染规则 — 源格式→物理卡面文字

> 本文件定义从 DZ 源格式到可印刷物理卡面文字的确定性转换规则。
> 转换是纯函数：相同源格式 → 相同卡面文字。

---

## 一、渲染总则

DZ 源格式本身已经非常接近自然中文，因此渲染的核心工作是：

1. **保留已有的自然语句**（大部分语句不需要改写）
2. **将标点记号转换为卡面约定**
3. **将约束标记转换为括号注释**
4. **格式化卡牌头**

---

## 二、卡牌头渲染

```
源: 浮光 [武学, 被动, 上限2]
渲: 【浮光】武学·被动·上限2

源: 儒家 [阵营, 生命8, 护甲2, 技力4]
渲: 【儒家】阵营 生命8 护甲2 技力4

源: 击敌 [基本牌, 品质:白, 数量:12张]
渲: 【击敌】基本牌·白（12张）
```

---

## 三、标点记号渲染

| 源格式 | 渲染 |
|--------|------|
| `条件描述：` | `条件描述，` |
| `？分支条件。` | `若分支条件，` |
| `·选项描述。` | `·选项描述` |
| `—常驻效果。` | 直接接在前文后 |
| `\` |

### 示例

```
源:
攻击时，翻牌堆顶1张判定牌。
？判定牌不是蓝也不是白。
  本次物理伤害翻倍。
？判定牌是蓝或白。
  获得这张判定牌。

渲:
攻击时，翻牌堆顶1张判定牌。若判定牌不是蓝也不是白，本次物理伤害翻倍。若判定牌是蓝或白，获得这张判定牌。
```

## 四、约束标记渲染

```
源: [约束]  →  渲:（约束）
源: [每回合限1次]  → （每回合限1次）
源: [上限4层]      → （上限4层）
源: [常驻]         → （常驻）
源: [与轻浮互斥]   → （与轻浮互斥）
```

---

## 五、标记引用

```
源: 「仁心」  →  渲: 「仁心」（保留原样）
源: 「噬魂」  →  渲: 「噬魂」
```

---

## 六、语句连接

同一条触发条件下的多个效果语句：

```
源:
受到伤害时，消耗1张紫卡，将此卡效果视为「免疫本次伤害」。
规避成功后，抽取1张基本牌。

渲:
受到伤害时，可消耗1张紫卡，将此卡效果视为「免疫本次伤害」。规避成功后，抽1张基本牌。
```

规则：两个独立效果之间用句号分隔；无额外空行。

---

## 七、完整示例

### 荆棘

```
源:
荆棘 [甲胄, 上限2]

  受到伤害后，对伤害来源使用「击敌」卡。
  该次攻击中额外造成1点物理伤害。

渲:
【荆棘】甲胄·上限2
受到伤害后，对伤害来源使用「击敌」卡，该次攻击中额外造成1点物理伤害。
```

### 儒家

```
源:
儒家 [阵营, 生命8, 护甲2, 技力4]

  核心技能：仁怀

    获得白或紫基本牌时，积累1个「仁心」标记[每回合最多3个]。

    消耗1个「仁心」，恢复1点技力。
    消耗1个「仁心」，抽取1张牌，随后恢复1点生命。

    回合结束时 |「仁心」不少于1个|，抽取1张牌。

    抽到的牌若有指定目标并使用之，额外获得1个「仁心」标记
    [与上条共享上限]。

渲:
【儒家】阵营 生命8 护甲2 技力4
仁怀：获得白或紫基本牌时，积累1个「仁心」标记（每回合最多3个）。消耗1「仁心」，恢复1点技力。消耗1「仁心」，抽1张牌，随后恢复1点生命。回合结束时有「仁心」，抽1张牌。抽到的牌若有指定目标并使用之，额外获得1个「仁心」标记（与上条共享上限）。
```

---

## 八、条件表达式渲染

```
源: |「仁心」不少于1个|
渲: 「仁心」≥1 或 有「仁心」

源: |「坚守」不少于3层|
渲: 「坚守」≥3层
```

---

*本规则确保卡面文字始终是自包含的自然中文，实体卡玩家无需任何外部参考即可理解效果。*
