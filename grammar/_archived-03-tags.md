# DZ 标签定义

> 本文档完整定义《对峙》全部 15 个标签。
> 每个标签包含：标签名、技能描述摘要、首次出现卡牌、设计意图、以及完整的 DZ 语法定义块。
> 所有标签定义块均可被卡牌源文件通过 `执行 [标签名]` 引用。

## 1. 韬光养晦

- **标签名**：韬光养晦
- **技能摘要**：消耗 1 张紫色品质基本牌，将其效果视为"免疫本次伤害"；规避成功后抽取 1 张基本牌。
- **首次出现**：浮光（构筑卡·武学）
- **设计意图**：以手牌为替代支付代价换取伤害免疫，体现"弃卒保车"的资源置换策略。紫卡本身具有高价值，消耗紫卡换取免伤是一种有代价的防御选择。

### DZ 语法定义

```
韬光养晦 [标签]:
  可消耗 1张紫卡 → 该紫卡效果视为「免疫本次伤害」
  规避成功后:
    抽取 1张基本牌
```

## 2. 一槌定音

- **标签名**：一槌定音
- **技能摘要**：翻牌堆顶 1 张作为判定牌；若判定牌为非蓝/非白品质，则将本次物理伤害翻倍；若判定牌为蓝/白品质，则获得该判定牌。
- **首次出现**：指虎（构筑卡·兵刃）
- **设计意图**：引入随机性验证的条件分支机制，令攻防结算存在变数。判定成功则伤害翻倍（高风险高回报），判定失败则补偿抽牌，增加博弈深度。

### DZ 语法定义

```
一槌定音 [标签]:
  翻牌堆顶 1张判定牌
  ? 判定牌为非蓝/非白:
    本次物理伤害 翻倍
  ? 判定牌为蓝/白:
    获得 判定牌
```

## 3. 谋定后动

- **标签名**：谋定后动
- **技能摘要**：从伤害、治疗、护甲三个互斥选项中择一执行。选择伤害则下次伤害+1；选择治疗则下次治疗+1；选择护甲则下次获得护甲+1。效果不可叠加。
- **首次出现**：蓄势（基本牌·蓝）
- **设计意图**：给予使用者一次性多选一决策权，覆盖伤害/治疗/护甲三个维度，体现"谋定而后动"的战术灵活性。使用者需根据当前局势做出最优选择。

### DZ 语法定义

```
谋定后动 [标签]:
  抉择:
    · 伤害 → 增加 下次伤害+1 [效果不可叠加]
    · 治疗 → 增加 下次治疗+1 [效果不可叠加]
    · 护甲 → 增加 下次获得护甲+1 [效果不可叠加]
```

## 4. 点石成金

- **标签名**：点石成金
- **技能摘要**：积累「材料」标记（上限 4 个），消耗「材料」标记并搭配不同的额外成本，产出不同的效果。三个配方分别为：护甲熔铸（材料+弃牌→护甲）、技力蒸馏（材料+生命→技力）、精华萃取（材料+技力→抽构筑卡）。每种配方每回合限 1 次。
- **首次出现**：药师（职业卡）
- **设计意图**：以通用标记「材料」为纽带构建多输出转化链路。同一标记搭配不同成本产出不同效果，体现"有限资源、有限选择"的设计理念。三个配方的成本各不相同，迫使玩家规划标记的分配。

### DZ 语法定义

```
点石成金 [标签]:
  回合开始时:
    获得 1个「材料」标记 [上限4]
  点石成金:
    · 消耗1「材料」+弃1手牌 → 获得 1点护甲 [每配方每回合1次]
    · 消耗1「材料」+耗1生命 → 获得 2点技力 [每配方每回合1次]
    · 消耗1「材料」+耗2技力 → 抽取 1张构筑卡 [每配方每回合1次]
```

## 5. 定向搜寻

- **标签名**：定向搜寻
- **技能摘要**：提供两种检索模式。构筑检索模式：从牌堆抽取 3 张指定类型的构筑卡，选择保留 2 张，其余弃置至构筑牌弃牌堆。基本牌模式：直接抽取 2 张基本牌。使用者二选一。
- **首次出现**：整军（基本牌·蓝）
- **设计意图**：定向从牌堆检索特定类型卡牌并择优保留，提升关键构筑卡的上手率。同时提供基本牌模式的保底抽牌，确保标签在无论何种局势下都有实用价值。

### DZ 语法定义

```
定向搜寻 [标签]:
  定向搜寻 [二选一]:
    · 构筑检索:
        抽取指定类型构筑卡 3张
        选择保留 2张
        弃置 剩余至构筑牌弃牌堆
    · 基本牌:
        抽取 2张基本牌
```

## 6. 藏锋蓄锐

- **标签名**：藏锋蓄锐
- **技能摘要**：将一张「御守」卡叠放至阵营卡上方作为蓄锐标记（每大回合仅可叠放 1 张）。当持有叠放「御守」且受到伤害时，弃置该叠放的「御守」，并减少本次伤害 1 点。
- **首次出现**：光铸（构筑卡·甲胄）
- **设计意图**：将手牌转化为延迟触发的待发标记，以"蓄而不发"换取时机优势。叠放的「御守」既是防御储备也是心理威慑——对手需考虑攻击是否会触发减伤。链接用后即解除，维持平衡。

### DZ 语法定义

```
藏锋蓄锐 [标签]:
  将该「御守」置于 阵营卡上方 [每大回合仅可叠放1张]
  持有叠放「御守」且受伤害时:
    弃置 该「御守」
    减少 本次伤害-1
```

## 7. 传檄征召

- **标签名**：传檄征召
- **技能摘要**：选择目标玩家，从其牌堆抽取并公示 1 张基本牌；强制目标在自身回合开始时直接使用该牌。若目标无基本牌，仍视为使用完毕（空发不返还）。
- **首次出现**：传令（基本牌·紫）
- **设计意图**：跨回合强制调度对手手牌。公示带来信息公开，强制使用打乱对手节奏。兼具干扰（破坏对手计划）与情报（获知手牌信息）双重价值。紫卡的品质定位体现了这种干扰能力的高价值。

### DZ 语法定义

```
传檄征召 [标签]:
  抽取并公示目标 1张基本牌
  强制目标在自身回合开始 使用该牌 [目标无基本牌时仍视为使用完毕]
```

## 8. 以形摹意

- **标签名**：以形摹意
- **技能摘要**：复制本回合已使用的上一张白/蓝/紫品质卡牌的全部效果；复制完成后额外获得 1 点技力。若本回合未使用非橙卡（无可复制对象），则兜底视为使用 1 张白色「击敌」卡（涉及资源消耗需正常支付）。
- **首次出现**：仿技（基本牌·橙）
- **设计意图**：灵活的镜像效果——以已用卡牌为模板复制执行，赋予橙色卡牌"万能牌"的定位。提供空场兜底确保永远可用（不会卡手）。额外技力回收降低了使用成本。是 15 个标签中唯一拥有兜底机制的标签。

### DZ 语法定义

```
以形摹意 [标签]:
  本回合已使用白/蓝/紫卡后:
    复制 已使用的白/蓝/紫卡效果
    额外获得 1点技力
  本回合未使用非橙卡:
    视为 "击敌"卡 [涉及资源消耗需正常消耗]
```

## 9. 追影逐风

- **标签名**：追影逐风
- **技能摘要**：指定目标的手牌数为基准 N，持续抽牌直至自身手牌数等于 N。若目标手牌数为 0，则改执行替代效果：抽取 2 张牌后弃置 1 张（净增 1 张）。
- **首次出现**：掠影（构筑卡·武学）
- **设计意图**：以对手手牌数为参照的追赶式抽牌机制。当对手手牌充裕时快速追平信息差；当对手空手时触发替代效果，确保标签在任何情况下都能产生价值。体现"如影随形"的追猎感。

### DZ 语法定义

```
追影逐风 [标签]:
  目标手牌≥1:
    持续抽牌至手牌数等于 目标手牌数量
  目标手牌为0:
    抽取 2张牌
    弃置 1张牌
```

## 10. 牵脉连心

- **标签名**：牵脉连心
- **技能摘要**：锁定两个单位，建立命运链接。下一次对任一锁定单位生效的效果，将同时作用于另一个锁定单位。链接效果用后即解除。
- **首次出现**：连脉术（构筑卡·术法）
- **设计意图**：建立两单位之间的命运链接，使下一次效果达成"一石二鸟"。可用于将单体伤害扩展为双目标伤害，或将单体治疗/增益同步给友方。链接用后即解除，避免滚雪球失控。

### DZ 语法定义

```
牵脉连心 [标签]:
  锁定 两个单位 [下次效果同时作用于两者，用后解除]
```

## 11. 洞幽察微

- **标签名**：洞幽察微
- **技能摘要**：查看并重新排列牌堆顶部 3 张牌的顺序；重排完成后抽取其中 1 张。
- **首次出现**：观微术（构筑卡·术法）
- **设计意图**：窥探牌堆顶信息（获取未来回合情报）后自由重排顺序（布局后续抽牌），再从中抽取 1 张（立即收益）。兼顾当前抽牌质量与后续回合布局，"观微"而知著。

### DZ 语法定义

```
洞幽察微 [标签]:
  重排 牌堆顶3张牌
  重排后:
    抽取 1张牌
```

## 12. 弃旧图新

- **标签名**：弃旧图新
- **技能摘要**：弃置手牌以换取可积累的战略资源——补充「谋略」标记。每回合限 2 次（通过重铸触发）。
- **首次出现**：兵家·权变（阵营核心技能，重铸子效果）
- **设计意图**：以牺牲手牌为代价换取可积累的战略资本「谋略」。「谋略」标记是兵家阵营的核心资源，可用于更换副职业身份、支付技能消耗等。非直接规避伤害，而是长线投资布局。

### DZ 语法定义

```
弃旧图新 [标签]:
  补充 1个「谋略」标记 [每回合限2次]
```

## 13. 崩山裂石

- **标签名**：崩山裂石
- **技能摘要**：消耗当前技力值的一半（向上取整）作为成本，使本回合下次攻击附加（消耗技力点数−1）点额外伤害。消耗的技力越多，附加的伤害越高，形成正比关系。
- **首次出现**：崩山（构筑卡·武学）
- **设计意图**：以资源当前值的半数为动态成本，资源越充沛效果越强，形成天然的自平衡机制。高技力时威力巨大，低技力时效果有限，迫使玩家在"攒技力爆发"和"及时使用"之间做权衡。

### DZ 语法定义

```
崩山裂石 [标签]:
  : 消耗当前技力一半（向上取整） → 使本回合下次攻击附加 （消耗技力点数-1）点伤害
```

## 14. 先损后利

- **标签名**：先损后利
- **技能摘要**：消耗自身 X 点生命值作为成本，对目标造成（消耗生命值 × 2）点物理伤害。以生命为直接交易成本，伤害与消耗成正比。
- **首次出现**：七伤（构筑卡·武学）
- **设计意图**：以生命为直接交易成本的高风险高回报转换机制。每消耗 1 点生命可造成 2 点伤害（2 倍转换率），体现"伤人先伤己"的狠厉风格。低血量时使用需格外谨慎——既可能逆转局势，也可能加速败亡。

### DZ 语法定义

```
先损后利 [标签]:
  : 消耗X点生命 → 造成 消耗生命值×2的物理伤害
```

## 15. 荆棘反刺

- **标签名**：荆棘反刺
- **技能摘要**：受到伤害后，对伤害来源发起反击——使用 1 张「击敌」卡（以正常攻击力进行基础攻击），且该次反击额外造成 1 点物理伤害。不阻止原伤害，仅在伤害结算后触发。
- **首次出现**：荆棘（构筑卡·甲胄）
- **设计意图**：以受伤为触发的被动反击机制。不阻止伤害（区别于免疫类标签），但在结算后惩罚攻击者。反击使用标准「击敌」卡且额外+1 伤害，形成"以牙还牙"的威慑——攻击荆棘持有者需要三思是否值得承受反伤。

### DZ 语法定义

```
荆棘反刺 [标签]:
  对伤害来源 使用 "击敌"卡
  该次攻击中:
    额外造成 1点物理伤害
```

### 引用方式

卡牌源文件中通过以下方式引用标签：

```
卡牌名 [类型, 属性]:
  触发条件:
    执行 [标签名]
```

示例：
```
浮光 [武学, 被动, 上限2]:
  受到伤害时:
    执行 [韬光养晦]
  规避成功后:
    抽取 1张基本牌
```

### 标签分类

| 分类 | 包含标签 | 特征 |
|------|---------|------|
| 防御型 | 韬光养晦、藏锋蓄锐、荆棘反刺 | 以不同方式应对/反击伤害 |
| 判定型 | 一槌定音 | 引入随机性分支 |
| 抉择型 | 谋定后动、定向搜寻、点石成金 | 多选一或多配方 |
| 资源型 | 弃旧图新、崩山裂石、先损后利 | 资源→效果的转换 |
| 信息型 | 洞幽察微、追影逐风、传檄征召 | 操控信息差或调度对手 |
| 联动型 | 牵脉连心、以形摹意 | 单位链接或效果复制 |
