# DZ 源格式语法规范

> DZ = 对峙。本文件是卡牌编辑器的唯一合法书写格式。
> 所有卡牌效果必须用此格式书写，解析器和渲染器均以此为准。

---

## 一、卡牌类型

### 1.1 五大类

| 大类 | 子类 | 游戏角色 |
|------|------|---------|
| 阵营卡 | — | 开局绑定，决定基础面板与专属标记 |
| 职业卡 | — | 每回合可发动一次的职业能力 |
| 构筑卡 | 兵刃 / 宝器 / 甲胄 / 武学 / 术法 | 装备在身上的卡牌 |
| 基本牌 | 白 / 蓝 / 紫 / 橙 | 从手牌打出 |
| 标记 | — | 附着于单位的不可见指示物，独立于卡牌管理 |

### 1.2 各类声明行

```
阵营卡：  儒家 [阵营, 生命8, 护甲2, 技力4]
职业卡：  斥候 [职业]
构筑卡：  浮光 [武学, 被动]
          指虎 [兵刃]
基本牌：  击敌 [基本牌, 白]
标记：    仁心 [标记]
```

**关于省略**：
- 构筑卡的"上限2张"是通用规则，不在声明行重复
- 基本牌的"数量N张"是发行配比数据，不在声明行重复
- 职业卡的消耗在效果文本中自然描述

## 二、效果书写（普遍规则）

### 2.1 语句形式

效果以自然中文语句书写，句号结尾。主语默认为"自身"，仅在主语不是自身时写出。

```
写法：
  受到伤害时，消耗1张紫卡，将本卡效果视为「免疫本次伤害」。
  规避成功后，抽取1张基本牌。
```

### 2.2 标点记号

| 记号 | 含义 | 用法 |
|------|------|------|
| `：` | 触发条件 | 条件行末尾，表示"当……时" |
| `—` | 常驻被动 | 行首，表示无条件持续生效 |
| `？` | 判定分支 | 行首，用于翻牌判定等**互斥分支** |
| `·` | 多选一 | 行首，用于配方/抉择等平行的互斥选项 |
| `[ ]` | 备注约束 | 行尾，表示次数/上限/互斥/补充说明 |
| `「」` | 标记名称 | 行中，引用标记 |

### 2.3 关于 `？` 的关键区分

`？` **仅用于真正的互斥判定**——即在一个判定点之后，根据判定的不同结果走向不同的分支，分支之间不能同时触发。

**互斥分支（用 `？`）：**
```
指虎 [兵刃]
  攻击时，翻牌堆顶1张判定牌。
  ？判定牌不是蓝也不是白。本次物理伤害翻倍。
  ？判定牌是蓝或白。获得这张判定牌。
```
（一张牌不可能同时是蓝/白又不是蓝/白——互斥）

**顺序触发（不用 `？`）：**
```
斥候 [职业]
  消耗1点技力，对目标造成1点物理伤害。
  若目标有护甲，获得1点技力，并将本次伤害转化为真实伤害。
  若目标有技力，本次伤害额外加1。
  若伤害被免疫或无效，抽取1张牌。
```
（每个"若"独立判断，可以顺序触发——非互斥）

### 2.4 多选一（配方/抉择）

```
药师 [职业]
  回合开始时，获得1个「材料」标记[上限4个]。

  点石成金：
    ·消耗1个「材料」并弃1张手牌，获得1点护甲[每配方每回合1次]。
    ·消耗1个「材料」并消耗1点生命，获得2点技力[每配方每回合1次]。
    ·消耗1个「材料」并消耗2点技力，抽取1张构筑卡[每配方每回合1次]。
```

### 2.5 备注约束

`[ ]` 仅包含四类内容：

| 类别 | 示例 |
|------|------|
| 次数限制 | `[每回合1次]` `[每大回合1次]` |
| 上限限制 | `[上限4层]` `[每回合最多3个]` `[最多+2]` |
| 互相排斥 | `[与轻浮互斥]` `[与云龙互斥]` |
| 补充说明 | `[常驻]` `[永久]` `[不消耗攻击次数]` `[可对自身使用]` |

### 2.6 禁止事项

| 禁止 | 正确做法 |
|------|---------|
| 效果行中途隐式切换主语 | 另起一行，显式写出新主语 |
| 一句中含两个核心动词 | 拆为两句 |
| 备注中含条件判断 | 用独立条件行表达 |
| 备注中含分支结果 | 拆为独立条目 |

## 三、支付与结算原则

> 这是游戏底层规则。所有卡牌效果的执行都必须遵守本节的时点顺序。

### 3.1 核心原则：先支付，后生效

任何效果的完整执行顺序为：

```
① 支付阶段 → ② 效果结算阶段 → ③ 后续连锁阶段
```

① **支付阶段**：消耗资源（技力、生命、手牌、标记等）。支付不可被免疫或无效化。支付一旦完成，资源不可退回（即使效果被免疫）。

② **效果结算阶段**：支付完成后，效果开始执行。如果效果被免疫，此阶段的结果被取消，但支付不退回。

③ **后续连锁阶段**：同一支付下的后续效果按书写顺序依次结算。

### 3.2 支付 vs 效果 — 严格区分

| 行为 | 归属 | 定义 | 是否可被免疫 |
|------|:--:|------|:--:|
| 消耗自己的技力/生命/手牌/标记 | **支付** | 主动付出资源以启动效果 | 否 |
| 弃置自己的手牌/装备 | **支付或效果** | 视书写位置而定：写在条件中=支付，写在效果中=效果 | 视情况 |
| 对目标造成伤害 | **效果** | 使目标损失生命 | 可被免疫 |
| 扣除目标的技力 | **效果** | 强制减少目标资源 | 不可免疫（非伤害） |
| 移除目标的护甲 | **效果** | 清除目标的护甲值 | 不可免疫（非伤害） |
| 移除目标的标记 | **效果** | 清除目标身上的标记 | 不可免疫（非伤害） |
| 清空自己的技力和护甲 | **效果** | 这是纯洁的濒死自毁行为，不是支付 | 不可免疫 |

**关键区分**：`消耗` 是主动支付，`扣除`（对目标）和 `移除` 是效果。即使对自己使用除障"移除"自己的护甲，那也是效果行为，不是支付。

### 3.3 数值引用的时点

效果描述中引用的数值，其取值时点遵循以下规则：

| 引用类型 | 取值时点 | 示例 |
|---------|---------|------|
| **消耗量**（"消耗了X点"） | 支付阶段（支付前计算应扣多少，扣除后即为消耗量） | `等同于技力消耗的法术伤害` |
| **当前值** | 效果结算阶段的即时状态 | `若目标有护甲`（检查伤害施加后目标是否仍有护甲） |
| **变化前的值** | 必须明确标注「变化前」 | `等同于清空前技力值的物理伤害` |
| **字段中的计数** | 字段中的当前值（支付和去除前） | `2+场上「噬魂」总数`（支付前计算总数） |

### 3.4 完整示例：纯洁（变化前引用的典型）

```
进入濒死状态时，弃置本卡并清空所有技力和护甲。
对1单位造成等同于清空前技力值的物理伤害。
```

执行顺序：
1. 触发条件满足 → 进入濒死状态
2. ②效果：弃置本卡 + 清空技力和护甲（技力变为0）
3. ③后续：计算"清空**前**的技力值"（如技力原为6，则伤害=6）
4. 对1单位造成6点物理伤害

关键：效果文本明确写了「清空前」，因此伤害用的是技力被清空之前的数值。

### 3.5 完整示例：崩山（消耗量引用）

```
消耗当前技力的一半并向上取整，使本回合下次攻击附加等同于(消耗技力减1)的伤害。
```

执行顺序：
1. ①支付：当前技力为7，一半向上取整=4。扣除4点技力（技力变为3）。
2. ②效果：消耗量=4，附加伤害=4-1=3。
3. 本回合下次攻击额外附加3点伤害。

关键：「消耗技力」指的是支付阶段实际扣除的量（4），不是支付前或支付后的技力值。

### 3.6 完整示例：七伤（支付后引用变化后的值）

```
消耗1点生命，造成等同于支付后当前生命值的物理伤害。
```

执行顺序：
1. ①支付：当前生命为8。扣除1点生命（生命变为7）。
2. ②效果：支付后当前生命=7，伤害=7。造成7点物理伤害。

关键：效果引用了「支付后」的当前生命值，这是支付完成后变化了的值。

### 3.7 实战速查表

| 卡牌 | 支付 | 效果引用的值 | 时点 |
|------|------|-------------|:--:|
| 崩山 | 消耗当前技力一半 | 消耗技力-1 | 消耗量本身 |
| 七伤 | 消耗1点生命 | 支付后当前生命值 | **变化后**（支付后生命） |
| 落雷术 | 消耗当前技力一半 | 消耗技力 | 消耗量本身 |
| 纯洁 | 清空（效果，非支付） | 清空前技力值 | **变化前**（明确标注） |
| 噬魂术 | 消耗(2+场上总数)技力 + 去除3个 | 濒死 | 支付用去除前总数 |
| 射手 | 释放标记（效果，非支付） | 释放张数 | 释放量本身 |
| 方士·烈焰 | 消耗2技力 | 若目标有护甲 | **变化后**（伤害后检查） |

## 四、阵营卡格式

```
阵营名 [阵营, 生命N, 护甲N, 技力N]

  核心技能：技能名

    效果语句...
    效果语句...
```

**示例：**

```
儒家 [阵营, 生命8, 护甲2, 技力4]

  核心技能：仁怀

    获得白或紫基本牌时，积累1个「仁心」标记[每回合最多3个]。

    抽到的牌指定目标并使用后，额外获得1个「仁心」标记。

    消耗1个「仁心」，恢复1点技力。

    消耗1个「仁心」，抽取1张牌。
    随后恢复1点生命。

    回合结束时若有「仁心」，抽取1张牌。
```

约束 `[每回合最多3个]` 放在第一条产生效果后，后续产生方式共享此上限。

## 六、构筑卡格式

### 6.1 声明行

```
卡名 [子类型, 被动/主动]
```

子类型：`兵刃` `宝器` `甲胄` `武学` `术法`

互斥关系作为备注写在效果行尾，不与声明行参数混排。

### 6.2 示例

**被动型：**
```
浮光 [武学, 被动]

  受到伤害时，消耗1张紫卡，将本卡效果视为「免疫本次伤害」。
  规避成功后，抽取1张基本牌。
```

**主动型：**
```
崩山 [武学, 主动]

  消耗当前技力的一半并向上取整，使本回合下次攻击额外附加等同于(消耗技力减1)的伤害。
```

**常驻型：**
```
长剑 [兵刃]

  —增加物理伤害1点[常驻]。
```

**带互斥的甲胄：**
```
云龙 [甲胄]

  受到单次伤害时，将伤害限制为最多2点[与轻浮互斥]。
  触发后，下回合技力恢复减少1点[最多累计减2]。
```

**带判定的兵刃：**
```
指虎 [兵刃]

  攻击时，翻牌堆顶1张判定牌。
  ？判定牌不是蓝也不是白。本次物理伤害翻倍。
  ？判定牌是蓝或白。获得这张判定牌。
```

## 七、基本牌格式

```
牌名 [基本牌, 品质]

  效果语句...
```

```
击敌 [基本牌, 白]

  消耗1次攻击次数，对目标造成等同自身攻击力的物理伤害[每回合1次]。
```

```
传令 [基本牌, 紫]

  抽取目标1张基本牌并公示，强制目标在自身回合开始时直接使用该牌
  [目标无基本牌时视为使用完毕]。
```

```
仿技 [基本牌, 橙]

  ？本回合已使用白、蓝或紫卡。复制那张卡的效果，并额外获得1点技力。
  ？本回合尚未使用非橙卡。将本卡视为1张白色「击敌」使用[涉及资源消耗仍须消耗]。
```

## 八、标记格式

标记是纯资源定义，**不描述任何卡牌效果**。效果由产生/消耗该标记的卡牌自行描述。

```
标记名 [标记]
```

**完整清单：**

```
仁心 [标记]    累计消耗型
自然 [标记]    累计消耗型
法令 [标记]    累计阈值型（只增不减）
坚守 [标记]    层数阈值型
谋略 [标记]    累计消耗型
零件 [标记]    累计消耗型
蓄力 [标记]    存储释放型
材料 [标记]    回合获取型
噬魂 [标记]    叠加引爆型
```

## 九、数值与条件表达式

数值用自然中文表达：

| 表达 | 含义 |
|------|------|
| 当前技力的一半并向上取整 | ceil(energy/2) |
| 消耗生命值2倍的物理伤害 | consumed_hp × 2 |
| 等同于蓝卡张数的伤害 | damage = count(blue_cards) |
| 伤害总量的一半并向下取整 | floor(total_damage/2) |
| 等同于清空前技力值的物理伤害 | pre_clear_energy |

## 十、新旧对比

**旧版（五段式表格，8 行）：**

```
浮光技能1：受到伤害时 → 自身 → 执行 → [韬光养晦] → —
[韬光养晦]定义：
| A | — | 自身 | 消耗 | 1张紫卡 | — |
| B | — | 该紫卡效果 | 视为 | 「免疫本次伤害」 | — |
浮光技能2：规避成功后 → 自身 → 抽取 → 1张基本牌 → —
```

**新版（DZ，5 行）：**

```
浮光 [武学, 被动]

  受到伤害时，消耗1张紫卡，将本卡效果视为「免疫本次伤害」。
  规避成功后，抽取1张基本牌。
```
