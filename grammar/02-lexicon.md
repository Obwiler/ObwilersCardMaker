# DZ 词条库

> 本文件列出 DZ 语法中所有合法词汇，按"条件词/谓语动词/宾语类型/备注约束"四类组织。
> 编辑器自动补全和语法校验以本文件为唯一依据。

## 第一章：条件词条

条件词出现在条件行（`X:`）中。分为四类。

### 1.1 消耗类

| 条件词 | 语义 | 典型卡牌 |
|--------|------|---------|
| `消耗N点技力` | 支付技力 | 斥候、谋士、方士 |
| `消耗N点生命` | 支付生命 | 七伤、饮冰 |
| `消耗N个「X」标记` | 支付标记 | 儒家、墨家 |
| `消耗当前技力一半（向上取整）` | 按比例支付 | 崩山 |
| `消耗当前技力一半（向下取整）` | 按比例支付 | 落雷术 |
| `弃置N张手牌` | 弃牌支付 | 兵家·权变 |
| `消耗N次攻击次数` | 消耗攻击机会 | 击敌 |
| `宣言额外消耗N技力` | 声明额外支付 | 巨弩、涌流 |
| `消耗N「X」+弃N手牌` | 复合消耗 | 药师 |
| `消耗N「X」+耗N生命` | 复合消耗 | 药师 |
| `消耗N「X」+耗N技力` | 复合消耗 | 药师 |

### 1.2 触发类

| 条件词 | 语义 | 典型卡牌 |
|--------|------|---------|
| `获得X时` | 获取某物时 | 儒家、射手 |
| `使用X后` | 使用卡牌/技能后 | 光铸、叠咒术 |
| `受到伤害时` | 被攻击瞬间 | 浮光、云龙、轻浮 |
| `受到伤害后` | 伤害结算后 | 荆棘、怜悯 |
| `造成伤害后` | 自身伤害结算后 | 吸灵术、噬魂术 |
| `回合开始时` | 小回合准备阶段 | 道家、祈福、药师 |
| `回合结束时` | 小回合结束阶段 | 儒家、止波 |
| `被攻击时` | 成为攻击目标时 | 黯然 |

| `敌方使用橙卡或消耗≥N资源的技能时` | 对方特定行动 | 反戈 |

| `进入濒死状态时` | 生命归零 | 纯洁 |

| `开局时` | 游戏初始化 | 兵家·权变 |

| `判定结果为X时` | 判定结果判断 | 指虎、摘星、定身术 |
| `规避成功后` | 免疫成功后 | 浮光 |
| `触发X后` | 某效果触发后 | 光铸 |

### 1.3 状态类

| 条件词 | 语义 | 典型卡牌 |
|--------|------|---------|
| `目标有X` | 目标存在某状态 | 斥候、方士 |

| `背包内每存在N张X` | 背包计数 | 金凌 |

### 1.4 时机/限制类

| `每回合N次` | 小回合限次 |
| `每大回合N次` | 大回合限次 |
| `每回合限N次` | 通用限次 |
| `每回合最多N个` | 单回合累计上限 |
| `最多N层` | 层数硬上限 |

## 第三章：宾语类型

### 3.1 数值类

| 宾语 | 说明 |
|------|------|
| `N点物理伤害` | 物理伤害 |
| `N点法术伤害` | 法术伤害 |
| `N点真实伤害` | 真实伤害（无视护甲） |
| `N点生命` | 生命值 |
| `N点护甲` | 护甲值 |
| `N点技力` | 技力值 |
| `伤害+N` | 伤害加成 |
| `伤害翻倍` | 伤害×2 |
| `当次伤害-N（最低0）` | 减伤 |
| `等同于蓝卡数量的伤害` | 变量伤害 |
| `消耗生命值×2的物理伤害` | 倍率伤害 |
| `等同于技力消耗的法术伤害` | 变量伤害 |
| `等同于清空前技力值的物理伤害` | 变量伤害 |

### 3.2 卡牌类

| 宾语 | 说明 |
|------|------|
| `N张基本牌` | 从基本牌堆抽取 |
| `N张构筑卡` | 从构筑牌堆抽取 |
| `N张手牌` | 手牌操作 |
| `N张牌` | 通用抽牌 |
| `判定牌` | 判定翻出的牌 |
| `X品质卡牌` | 指定品质 |
| `牌堆顶N张` | 牌堆顶部操作 |

### 3.3 标记类

| 宾语 | 说明 |
|------|------|
| `N个「X」标记` | 标记操作 |
| `N层「X」标记` | 以层数累加 |
| `1张为「X」` | 卡牌存储为标记 |

### 3.4 资源类

| 宾语 | 说明 |
|------|------|
| `N点生命` | 生命资源 |
| `N点护甲` | 护甲资源 |
| `N点技力` | 技力资源 |
| `技力上限±N` | 上限变化 |
| `初始护甲+N` | 开局护甲 |
| `物理伤害+N` | 物伤加成 |
| `法术伤害+N` | 法伤加成 |
| `法术抗性+N` | 法抗加成 |
| `额外装备空间` | 装备栏+1 |

### 3.5 状态/单位类

| 宾语 | 说明 |
|------|------|
| `目标` | 效果指向 |
| `自身` | 效果来源 |
| `伤害来源` | 伤害发起者 |
| `攻击者` | 攻击发起者 |
| `两个单位` | 两个目标 |
| `其他玩家` | 非自身玩家 |
| `其他单位` | 非自身单位 |
| `1单位` | 任意单位 |

## 第四章：备注约束

仅四类合法备注：

### 4.1 频率限制

```
[每回合限1次]
[每大回合1次]
[每回合最多2次]
[每配方每回合1次]
[每回合仅可使用1次（含复制体）]
[每大回合仅可叠放1张]
[每回合最多N个]
```

### 4.2 上限限制

```
[上限4]
[上限2个]
[最多4张]
[最多2张]
[最多累计-2]
[最多+2]
[无上限]
[最低为0]
```

### 4.3 互斥关系

```
[与轻浮互斥]
[与云龙互斥]
[效果不可叠加]
```

### 4.4 扩展说明

```
[常驻]
[永久]
[被动]
[一次性]
[不消耗攻击次数]
[仅抵消当次伤害]
[可对自身使用]
[开局即生效]
[触发后弃置]
[弃置的牌归入构筑牌弃牌堆]
[二选一]
[三选一]
[兜底效果]
```

## 第五章：特殊主语

仅在主语≠自身时使用：

| 主语 | 语义 | 典型卡牌 |
|------|------|---------|
| `对目标` | 效果指向单个目标 | 击敌、医师 |
| `对1单位` | 任意单位 | 寻岚、纯洁 |
| `对伤害来源` | 伤害发起者 | 荆棘 |
| `攻击者` | 攻击发起者 | 黯然 |
| `目标` | 被操作对象 | 巨弩、重锤 |
| `其他玩家` | 除自身外玩家 | 谋士 |
| `其他单位` | 除自身外单位 | 止波 |
| `该紫卡效果` | 卡牌拟人化主语 | 浮光 |
| `该次攻击` | 攻击事件拟人化 | 荆棘 |
